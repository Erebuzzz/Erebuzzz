## Top projects

**ScribeAI** — Real-time meeting assistant capturing dual-channel audio via WebRTC, streaming to a backend queue, using Google Gemini for live transcription and summarization. Session persistence + secure auth.
- Stack: Next.js, TypeScript, Socket.io, Node.js, Google Gemini API, PostgreSQL (Prisma), Better Auth, TailwindCSS.
- Links: [Live](https://scribe-ai-zeta.vercel.app) · [Repo](https://github.com/Erebuzzz/ScribeAI)

**PathOptix** — Intelligent navigation with a custom PyTorch model predicting congestion (92% confidence). Optimizes routes for fuel, cost, and environmental impact via FastAPI backend.
- Stack: Python, PyTorch, FastAPI, React (Vite), Google Maps API, TailwindCSS.
- Links: [Live](https://pathoptix-intelligent-real-time-nav.netlify.app) · [Repo](https://github.com/Erebuzzz/PathOptix-Intelligent-Real-Time-Navigation-Engine)

**Cryptopad** — Zero-knowledge text sharing with client-side AES-256 + HMAC, burn-after-read and timed expiry on ephemeral edge storage. Server never sees raw data.
- Stack: Next.js, TypeScript, AES-256, HMAC, Zeabur (Edge Functions).
- Links: [Live](https://cryptopad-beta.vercel.app) · [Repo](https://github.com/Erebuzzz/Cryptopad)

**AI Code Plagiarism Detector** — Multi-agent LLM orchestration (Cohere, Together.ai, Replicate) + Python AST analysis + ensemble scoring + Monaco editor UI.
- Stack: React, Flask, Python AST, Vector Embeddings (Cohere/Together), TailwindCSS.
- Links: [Live](https://code-plagiarism-detector.vercel.app) · [Repo](https://github.com/Erebuzzz/Code-Plagiarism-Detector)

**Humor Identification Model** — Research project detecting humor in Yelp reviews (87% accuracy) with Zagreb indices + lexical ambiguity features in an SVM/NB/NN stacking ensemble.
- Stack: Python, PyTorch, BERT, Word2Vec, Graph Theory (NetworkX), Scikit-learn.
- Links: [Repo](https://github.com/Erebuzzz/Humor-Identification-Model)

**Hybrid Movie Recommendation System** — Hybrid CF (SVD) + content-based on MovieLens 100k with OMDb/TMDb enrichment to solve cold-start.
- Stack: Python, Scikit-learn, SVD, Streamlit, OMDb API, TMDb API.
- Links: [Live](https://movie-recommendation-system-tmdb-hybrid.streamlit.app) · [Repo](https://github.com/Erebuzzz/Movie-Recommendation-System)

**TextLexiq** — Smart document companion: OCR images/papers, convert to PDF/Word/LaTeX, summarize, QA, and extract insights with on-device AI for speed and privacy.
- Links: [Repo](https://github.com/Erebuzzz/TextLexiq)
